# 16 — UI Design System

## الهدف
واجهة Enterprise حديثة واحترافية وموحدة بين Android وWindows.

## مبادئ
- RTL أولًا.
- وضوح المعلومات.
- سرعة POS.
- Responsive.
- Accessibility.
- Light/Dark.
- حالات Loading/Empty/Error/Offline.

## Components
- App Bar.
- Navigation.
- Cards.
- Buttons.
- Inputs.
- Dropdowns.
- Tables.
- Data Grid.
- Dialogs.
- Bottom Sheets.
- Charts.
- Toast/Snackbar.
- Status Badges.

## لكل شاشة
يجب توثيق:
```text
Purpose
Reference
Data
Actions
States
Permissions
Navigation
Offline Behavior
Sync Behavior
```

## قاعدة التصميم
إذا توجد واجهة مرجعية معتمدة، فهي مصدر التصميم. لا يعاد اختراع النصوص أو الأيقونات أو التقسيم دون موافقة.
