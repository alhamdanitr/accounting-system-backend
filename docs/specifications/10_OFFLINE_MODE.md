# 10 — Offline Mode

## المبدأ
Offline ليس وضع قراءة فقط؛ العمليات الأساسية تستمر محليًا.

## يعمل Offline
- المنتجات.
- البحث.
- المبيعات.
- المشتريات.
- المخزون.
- العملاء.
- الموردون.
- القبض والصرف حسب الصلاحيات.
- الطباعة المحلية.
- التقارير المحلية المتاحة.

## عند العودة
تبدأ المزامنة تلقائيًا عبر WorkManager/Background Service مناسب.

## يجب اختبار
- انقطاع الإنترنت أثناء الحفظ.
- إغلاق التطبيق أثناء المزامنة.
- انقطاع الكهرباء.
- إعادة الإرسال.
- تكرار الطلب.
- تعارض جهازين.
- استعادة بعد الفشل.

## قاعدة
لا تظهر للمستخدم رسالة نجاح مزامنة إلا بعد ACK فعلي من الخادم.
