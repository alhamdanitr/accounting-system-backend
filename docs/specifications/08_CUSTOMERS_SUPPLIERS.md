# 08 — Customers & Suppliers

## Customer
- الاسم.
- الهاتف.
- العنوان.
- حد الائتمان.
- الرصيد.
- إجمالي المبيعات.
- المدفوع.
- آخر حركة.

## Supplier
- الاسم.
- الهاتف.
- العنوان.
- الرصيد.
- إجمالي المشتريات.
- المدفوع.
- آخر حركة.

## كشف الحساب
```text
Opening Balance
+ Sales/Purchases
- Payments
- Returns
± Adjustments
= Closing Balance
```

## قواعد
- كل حركة مرتبطة بمصدرها.
- كشف الحساب قابل للطباعة وPDF وWhatsApp.
- منع تعديل الرصيد يدويًا دون Adjustment موثق.
