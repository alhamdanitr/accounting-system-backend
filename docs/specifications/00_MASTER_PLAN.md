# 00 — Master Plan

## الهدف
بناء نظام محاسبي وإدارة مخزون احترافي لمحل أدوات الشبكات والإلكترونيات يعمل على Android وWindows، ويدعم Online/Offline والمزامنة بين الأجهزة.

## نطاق النظام
- المبيعات والمشتريات.
- المخزون والمخازن والجرد.
- العملاء والموردون والديون.
- الخصومات والمرتجعات.
- السندات والصناديق والمصروفات.
- المحاسبة والتقارير.
- الطباعة وPDF.
- WhatsApp.
- الصلاحيات والتدقيق.
- Offline-First والمزامنة.
- Android + Windows + Backend.

## المبدأ
صحة البيانات والمحاسبة والمخزون والمزامنة أهم من جمال الواجهة. أي ميزة يجب أن تكون قابلة للاختبار والتدقيق.
