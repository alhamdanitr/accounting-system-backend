# 18 — Windows

## الهدف
Desktop POS وإدارة كاملة للشركة.

## التقنية المقترحة
Kotlin + Compose Multiplatform قدر الإمكان مع مشاركة Domain/Sync/Models.

## UX
- Mouse + Keyboard.
- اختصارات POS.
- Data Grid.
- Multi-column layouts.
- Print management.
- Barcode scanner USB.
- Large screen dashboard.

## الوظائف
Dashboard, POS, Products, Inventory, Sales, Purchases, Customers, Suppliers, Accounting, Reports, Printing, Settings.

## Acceptance
اختبار الوظائف نفسها الموجودة على Android مع تحسينات Desktop الخاصة بالإدخال والطباعة.
